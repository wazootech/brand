# Typography

## Primary Typeface

| Role | Font | Weight | Source |
|------|------|--------|--------|
| Brand body | **IBM Plex Mono** | 400, 500 | Google Fonts |
| Brand headings | **Inter** | 400, 600 | System / Google Fonts |

## IBM Plex Mono

Used for all brand body copy, code snippets, and marketing text. The monospace aesthetic reinforces the technical, developer-focused identity.

```css
font-family: "IBM Plex Mono", monospace;
font-weight: 400;
letter-spacing: -0.025em;
```

## Inter

Used for the wordmark logotype and UI labels where a clean, modern sans-serif is needed.

```css
font-family: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
font-weight: 600; /* wordmark */
letter-spacing: -0.02em;
```

## Typographic Scale

| Element | Size | Weight | Color |
|---------|------|--------|-------|
| H1 / Brand name | 2.25rem | 600 | `white` |
| H2 / Section | 1.5rem | 600 | `white` |
| Body | 1.125rem | 400 | `text` |
| Caption / Meta | 0.875rem | 400 | `text-muted` |
| Badge | 0.875rem | 600 | `void` bg / `white` text |

## Usage Rules

- Body text should sit on `letter-spacing: -0.025em` for a tighter, more modern feel
- Avoid using more than 2 font weights in a single composition
- IBM Plex Mono is required for any code-adjacent content (descriptions, docs)
- Inter is reserved exclusively for the wordmark and logo lockups
